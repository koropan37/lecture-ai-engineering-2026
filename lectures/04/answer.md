    - 問題の要約とメモ
    1. astropy__astropy-12907 
        python の天文学向けのライブラリ astropy/astropy にあるバグの修正。
        複数の計算モデルを & 演算子で連結した際、各モデルの入出力の独立性（分離可能性）を判定する関数 separability_matrix が誤った結果を返す。
        A, B, Cを & を使って並べる際に、B, Cを変数に入れてAと繋げると、独立した計算になってないと誤判定になる。
        人間が直そうと思うと、関数の特定の使い方でしか発生しないためバグの原因の特定が難しそう。
        LLMが直す際も、どこにバグの原因があるのかを調べるのに苦労しそうだと考える。
    
    2. django__django-11099
        python の web フレームワーク である Django のURLが正しい形式かチェックする機能（URLValidator）の正規表現のバグの修正。
        コロン(:)や @ などのパーセントエンコーディングをしなければいけないものを、そのままでも正しいものとしてあ使っていた。
        私も WebSocket を作成する際の http の validation をしたことがあるため、知識があれば問題の特定と治すことは難しくないと考える。LLMではどの文字がダメで、クエリ文字などがきた際の挙動の確認をしっかりしないと解決したと判断したが、まだ問題が残っていることが起きそう。

    3. matplotlib__matplotlib-13989
        python のグラフ描画ライブラリ matplotlib で ヒストグラムを描画する plt.hist() 関数で、特定のオプションを同時に指定すると範囲設定（range）が無視されるバグの修正。
        bins="auto", range=(0, 1), density=True を同時に渡すとバグが発生。
        issue 報告に原因のコミットが書かれているため、変更前後をみてテストを追加していけば原因の特定はできそう。
        人間よりもLLMの方が網羅的にできて得意そうだと考える。
    
    - 作成の人数と手順
    OpenAI のブログより、python が得意な93人の開発者が協力 
    SWE-bench には解決不可能な問題があった。そのような問題点を解決するために、人間のアノテーターが

    これらを3人のアノテーターがそれぞれ判断しラベル付。
    最終的に500問にまとめ、SWE-bench用の評価ツールを作成し、問題環境を整えた。
    https://openai.com/ja-JP/index/introducing-swe-bench-verified/
